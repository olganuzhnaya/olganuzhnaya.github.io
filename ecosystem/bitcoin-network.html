BITCOIN NETWORK

The Architecture of a Decentralised Network

Discover how Bitcoin participants communicate, how transactions are verified, how blocks are connected and how the network maintains a shared transaction history without a central controlling authority.

PEER-TO-PEER NODES CONSENSUS SECURITY

1. What Is the Bitcoin Network?

Bitcoin is a decentralised peer-to-peer electronic payment system. Its network consists of independently operated computers that communicate with one another using a shared protocol.

Instead of relying on one central server to maintain the transaction history, Bitcoin uses a distributed network of participants. These participants perform different tasks, including transmitting transactions, verifying data and maintaining copies of the blockchain.

The network does not have a single organisation that controls every participant. Individual operators decide which software to run and which connections to maintain.

2. Peer-to-Peer Architecture

Peer-to-peer architecture allows participating computers to communicate directly with one another rather than depending on a central communication server.

Bitcoin nodes establish connections with other nodes. They can exchange information about transactions, blocks and the state of the network.

When a node receives new transaction data, it can check the information according to its own validation rules before relaying it to connected peers.

This communication structure helps information spread throughout the network. It does not mean that every computer communicates directly with every other computer.

3. Nodes: Participants in the Network

A Bitcoin node is a computer running software that participates in the Bitcoin network.

Nodes can receive and relay information. A fully validating node independently checks transactions and blocks against the consensus rules implemented in its software.

Full Nodes

Full nodes independently validate blocks and transactions. They help enforce the network's consensus rules and can maintain a local copy of blockchain data.

Mining Nodes

Miners assemble candidate blocks and perform Proof of Work calculations. Mining is a specialised activity within the broader Bitcoin network.

Important Distinction

Not every Bitcoin node is a miner. A person can operate a full node without participating in mining. Likewise, users who send and receive Bitcoin do not necessarily operate their own nodes.

4. Transactions and Data Propagation

A Bitcoin transaction describes how previously available bitcoin value is spent and assigned to new outputs. Transactions are constructed and authorised using cryptographic signatures.

After a transaction is broadcast, nodes can receive it, check whether it follows their validation rules and relay it to other connected nodes.

Valid transactions may wait in a node's memory pool, commonly called the mempool, before being included in a block.

A transaction is not confirmed merely because it has been broadcast or received by another participant. Confirmation occurs when it is included in a block accepted by validating nodes.

5. Blocks and the Blockchain

Bitcoin transactions are organised into blocks. Each block contains transaction data and a block header with information that connects it to the preceding block.

This cryptographic linking creates a chronological chain of blocks, known as the blockchain.

Each block header includes the hash of the previous block. Changing historical data would therefore require rebuilding the subsequent Proof of Work and competing with the work supporting the accepted chain.

Nodes independently validate new blocks before accepting them as part of their view of the blockchain.

6. Consensus and Proof of Work

Bitcoin uses a consensus mechanism based on Proof of Work and a set of protocol rules followed by validating nodes.

Miners repeatedly calculate hashes of candidate block headers, searching for a result that satisfies the network's current difficulty target.

Finding a valid Proof of Work requires computational effort. Other nodes can verify the result independently.

Proof of Work helps determine which valid chain has accumulated the greatest amount of work. However, nodes do not simply accept any block produced by a miner: blocks must also comply with their consensus rules.

7. Network Security

Bitcoin's security depends on several interacting elements rather than one isolated technology.

  • Independent validation: full nodes check transactions and blocks against consensus rules.
  • Cryptography: digital signatures and hash functions support transaction authorisation and data integrity.
  • Proof of Work: mining requires computational resources to produce valid blocks.
  • Distributed operation: independently operated nodes maintain and verify network data.
  • Economic incentives: mining rewards and transaction fees form part of the system's incentive structure.

These mechanisms do not eliminate every possible risk. Network concentration, software vulnerabilities, operational failures and attacks on individual users remain important security considerations.
