Ethereum

Ethereum is a decentralized blockchain platform designed for smart contracts and decentralized applications. It uses the Ethereum Virtual Machine (EVM) and a Proof-of-Stake consensus mechanism.

Technology

Ethereum introduced programmable blockchain technology through smart contracts. Applications can run on the Ethereum network without relying on a central server. The Ethereum Virtual Machine (EVM) provides a standard environment for executing smart contract code.

History

Ethereum was proposed in 2013 by Vitalik Buterin. The Ethereum network launched in 2015. In 2022, Ethereum completed "The Merge", transitioning from Proof-of-Work to Proof-of-Stake consensus.
